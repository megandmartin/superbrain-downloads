# SuperBrain public images

These images introduce the public desktop preview. The screenshots show the fictional **Northstar Studio** demo company; figures, records and recommendations are examples.

| Image | Use |
| --- | --- |
| [readme-hero.png](readme-hero.png) | README header, 1280 × 640 pixels. |
| [social-preview.png](social-preview.png) | Repository link preview, 1280 × 640 pixels, under 1 MB. |
| [desktop.webp](desktop.webp) | Actual Mac preview: decisions, company goals and records. |
| [ask.webp](ask.webp) | Actual Mac preview: Ask and suggested tasks. |
| [privacy.webp](privacy.webp) | Actual Mac preview: Local and Connected mode controls. |
| [logo.svg](logo.svg) | SuperBrain brand mark. |

The screenshots and brand mark are also used on the [public SuperBrain website](https://superbrain-desktop.vercel.app). The header composes that existing imagery; it does not represent a new application build.

GitHub's social preview is a separate repository setting. A maintainer can select **Settings → General → Social preview → Edit → Upload an image** and choose `social-preview.png`. Adding an image file to the repository alone does not change the repository's share card. [GitHub's instructions](https://docs.github.com/en/repositories/managing-your-repositorys-settings-and-features/customizing-your-repository/customizing-your-repositorys-social-media-preview).
