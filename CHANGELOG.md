# Release history

This history covers public desktop downloads. Documentation and repository improvements do not change the version of the installed app.

## 3 November 2026 — Public preview resources

- Added a product introduction with actual Mac demo screenshots and clearer platform downloads.
- Added a getting-started walkthrough, local-data and backup guidance, and a platform verification summary.
- Added focused bug and improvement forms for public preview feedback.
- Added a versioned release manifest, download integrity verifier and automated repository checks.

These changes improve the public repository. The app downloads remain at **0.3.0-preview.1**.

## 0.3.0-preview.1 — 29 October 2026

[Release notes and downloads](https://github.com/megandmartin/superbrain-downloads/releases/tag/v0.3.0-preview.1)

- Published the Apple Silicon Mac desktop preview for macOS 14 or later.
- Published an earlier Windows 10/11 x64 candidate with narrower verification.
- Included SHA-256 checksums and third-party runtime/model notices alongside the installers.
- Offered local search and an optional, separately downloaded generation model. The Mac preview includes resumable model downloads and the later structured-recommendation retrieval fixes.

Both installers are unsigned distribution previews. The Mac app is ad-hoc signed and not notarized. Windows installation, local generation and physical microphone checks remain pending. See the [platform status and known limits](docs/preview-status.md) before installing.
